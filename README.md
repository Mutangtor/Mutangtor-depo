# Mutangtor-depo
Bu mod, yarışlarını otomatik olarak kaydeder ve daha sonra tekrar izlemenizi sağlar.

Scripts klasörünü ana dosyaya atın.

Gereksinimler
ASI Loader (ör. dinput8.dll) oyunun ana klasöründe bulunmalıdır.




Kullanım:
Kayıt, yarış başladığında otomatik olarak başlar.
Yarış bittikten sonra ana menüye dönün ve 4 tuşuna basarak kaydı kaydedin.

Replay izleme

4: Replay kaydet

5: Replay dosyası seç.

3: Seçilen replay'i oynat.



7: Oynatma hızını artır.

6: Oynatma hızını azalt.




Tuşları değiştirme
İsteğe bağlı NFSUReplayModeSettings ayar aracıyla tuş atamalarını değiştirebilir 
ve bilgi göstergesi seçeneklerini düzenleyebilirsiniz. Ama bu derlenmiş hali, derlenmemiş kaynak kod halinde mümkün.
